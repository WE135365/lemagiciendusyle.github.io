# LE MAGICIEN DU STYLE

**Votre style, votre élégance, votre Magie.**

Le Magicien du Style is an online fashion and lifestyle store offering clothing, shoes, accessories, fabrics, home textiles, and products for the whole family.

## Store Categories

- Women
- Men
- Shoes
- Accessories
- Home
- Kids

## Project Features

- Responsive online storefront
- Product catalog and image galleries
- Product category filters
- Shopping cart and order summaries
- WhatsApp ordering
- Administration panel for products and orders
- Node.js server and API

## Technologies

- HTML
- CSS
- JavaScript
- Node.js

## Project Structure

- `index.html` — Online store
- `admin.html` — Administration panel
- `server.js` — Server and API
- `data/` — Product, order, and store settings data
- `imagen/` — Product and storefront images

## Important Security Notes

Never publish administrator passwords, session secrets, or customer information in this repository. Configure sensitive values as environment variables on your hosting provider.

## Brand Mission

Our mission is to make style, elegance, and quality accessible to everyone.
